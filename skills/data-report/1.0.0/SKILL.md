# Data report

Inspect columns, row count, units, date ranges, missing values and duplicate keys before analysis. Establish the observation unit and denominator for every rate. Do not silently discard rows; report exclusion rules and counts.

Compute descriptive statistics appropriate to the distribution and question. Segment only when sample sizes support useful comparisons. Separate correlation from causal explanation. Check totals against the source and preserve enough calculation detail for a second analyst to reproduce the result.

Use charts only when they reveal a pattern more clearly than a compact table. Label axes and units; preserve chronological order for time series. Mark missing data separately from zero.

Deliver the main finding, supporting figures, limitations and reproducible calculations. If the dataset is incomplete, bound the conclusion instead of filling in missing values with assumptions.
