# Landing page design

Inspect the existing entry route, layout, shared styles and available assets before editing. Preserve the framework, routing and user changes. Identify the audience, primary action and content hierarchy from the actual brief.

Choose a visual direction that fits the product: type scale, background, accent and spacing. Establish reusable CSS tokens. Use supplied assets or original CSS/SVG primitives; do not invent customer logos, testimonials or performance numbers.

Implement the complete route, including loading/empty/error states for real data. Interactive controls must perform the action they advertise. Keep prose, numeric information and navigation readable at 390px and desktop widths.

Check keyboard focus, headings, form labels, color contrast and reduced-motion behavior. Render in a browser and inspect both desktop and mobile. Check for overflow and broken links; run the project's existing build and tests relevant to changed behavior.

Deliver the route and changed files, state what was verified and distinguish actual product metrics from examples. Refer to references/review.md for the final visual pass.
